## Actividades Realizadas

Durante esta sesión de trabajo se analizó la documentación y la estructura del repositorio `ECommerce-Grocery-Store` para modelar gráficamente el sistema. Las actividades específicas fueron:

- Análisis de los requerimientos y roles del proyecto para identificar las interacciones principales.
- Revisión detallada de las conexiones y llaves foráneas de la base de datos para mapear la estructura del sistema.
- Diseño y estructuración del Diagrama de Casos de Uso, detallando las acciones exclusivas y compartidas entre el Cliente y el Administrador.
- Diseño y estructuración del Diagrama Entidad-Relación (ER), incluyendo las entidades principales, la tabla puente para calificaciones y las relaciones del administrador con productos y personal.
